# Онто

Публичный репозиторий онтологической платформы Онто. Здесь публикуются открытые методологические материалы и принимаются сообщения об ошибках платформы.

## Методология ведения проекта разработки ПО

[Методология ведения проекта разработки ПО](methodology/software-development-methodology.md) описывает практический каркас, который помогает сохранить контекст работы и проследить путь от причины её появления до подтверждённого результата.

Методология не задаёт единственно правильный процесс и не заменяет принятые в организации подходы к управлению разработкой. Она может быть адаптирована к условиям конкретного проекта. Онто используется в документе как прикладной пример реализации методологии через связанную модель проекта.

Текущая публичная версия: **1.0.0**.

## Платформа Онто

Онто — онлайн-платформа для моделирования и управления знаниями. Она позволяет работать с общей связанной моделью визуально, таблично и текстово, в том числе с помощью AI-ассистентов.

Сайт: [ontonet.ru](https://ontonet.ru/)
